# Running the code
## Step 1: Clone this repository
Clone this repository by using the following command and open the new folder containing the source code on your terminal:
```
git clone https://github.com/Apower11/PriceProphetQMUL.git
```
## Step 2: Run the reverse proxy
To run the reverse proxy enter these commands into your terminal when in the project folder:
```
cd backend
node main.js
```
## Step 3: Run the go backend
Find the go backend by navigating to this link: https://github.com/Apower11/derivatives-pricing-microservice.
Then clone that repository on your local machine and follow the README.md file on it to get it running before going on to the next step.
## Step 4: Run frontend
To run the frontend run these two commands:
```
npm i
ng serve
```
# Testing the code
Run this command to run the tests:
```
ng test
```
